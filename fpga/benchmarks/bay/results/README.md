# benchmarks/bay/results

Result files from the bay reference tests, one per run:
`<YYYY-MM-DD-HHMMSS>-<hostname>-<test>-<BDF with : as _>.txt`, `<test>` one of `lspci`, `iommu`, `dmesg`,
`suspend`. Commit the runs that answer something (the day-one Dual M.2 run, each card spin), and say in the
commit which device was in the bay. Dry runs on other machines are not committed.
